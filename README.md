# Sidharth Gupta — Developer Portfolio

A responsive, clean white-and-blue portfolio website built with **HTML, CSS, and vanilla JavaScript**.

## Features

- Responsive layout for mobile, tablet, and desktop
- About section and skills based on supplied profile details
- GitHub and LinkedIn links
- Project section that does not invent projects or achievements
- Mobile navigation menu
- Accessible skip link and reduced-motion support
- No build step or framework required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the **Live Server** extension in Visual Studio Code.

## Deploy to Vercel for free

### Option A: Deploy from GitHub (recommended)

1. Create a repository on GitHub, for example `sidharth-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Sign in to [Vercel](https://vercel.com/) using your GitHub account.
4. Choose **Add New → Project**, then import `sidharth-portfolio`.
5. For a plain HTML site, leave the framework preset as **Other** and leave the build command and output directory empty unless Vercel asks otherwise.
6. Click **Deploy**. Vercel will provide a public URL such as `your-project.vercel.app`.

### Option B: Deploy with Vercel CLI

1. Install Node.js from [nodejs.org](https://nodejs.org/).
2. In a terminal, install the Vercel CLI:
   ```bash
   npm install -g vercel
   ```
3. Open the project folder in the terminal and run:
   ```bash
   vercel
   ```
4. Follow the prompts. For a production deployment, run:
   ```bash
   vercel --prod
   ```

## Before publishing

- Check your GitHub and LinkedIn URLs.
- Add real projects to the Projects section when you have them.
- If you want to display an email address, add one you are comfortable making public.
